## Abstract

The Blood Bank Inventory and Donor Matcher is a project designed to manage blood bank inventory and help identify suitable blood donors based on blood group requirements. The system aims to organize blood stock information and simplify the process of finding compatible donors when blood is needed.

## Project Structure

- `src/` – Source code of the project
- `docs/` – Project documentation
- `data/` – Dataset or documented data source references
- `results/` – Project outputs and results
- `reports/` – Phase-wise project reports
